# Vinexus Application

Vinexus full-stack repository organized into separate `backend` and `frontend` modules.

## Repository Structure

```
Vinexus/
├── backend/    # Node.js + Express + MongoDB REST API backend
└── frontend/   # Frontend web application (Upcoming)
```

## Quick Start

### Backend Setup
To run the backend server:

```bash
cd backend
npm install
npm run dev
```

For more details on backend API endpoints and configuration, see [backend/README.md](file:///c:/Rays%20software/MERN%20Workspace/Vinexus/backend/README.md).
