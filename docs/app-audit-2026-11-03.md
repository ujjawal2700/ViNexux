## Removing the production skips

The three notification specifications previously skipped 11 cases in production-preview mode because their Firebase mocks intercepted development source-module URLs. They now share `tests/e2e/firebaseMock.js`, which supplies the same fixture to development modules and compiled browser responses. The compiled adapter is located by parsing JavaScript and checking its configuration guard and diagnostic markers. An unexpected build shape fails the test rather than silently omitting coverage.

Only browser test responses are modified. Application source and compiled assets on disk are unchanged. `@babel/parser` is now an explicit test dependency. The existing registration, permission, subscription, foreground-message and logout assertions remain in place. No skip declarations remain in the test directories.
